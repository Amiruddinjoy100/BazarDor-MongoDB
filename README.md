# 🛒 বাজার দর — BazarDor

Bangladesh's essential-goods price tracker, built with **Next.js App Router, Tailwind CSS, Better Auth and MongoDB**.

## Start here

1. Install **Node.js 20.9+** (Node 22 recommended), run `npm install`.
2. Copy `.env.example` to `.env.local`. Replace MongoDB Atlas URI, auth secret, and auth URL.
3. Run `npm run dev`, then open `http://localhost:3000`.

More setup, features and deployment notes will be added before handoff.
